# NEON STORM

Неоновый аренный 2D-шутер в браузере: бесконечные волны, боссы, 6 видов оружия, 18 улучшений.
Вся графика и звук генерируются кодом — никаких ассетов.

**Играть:** https://backwardzz.github.io/neon-storm/

## Режимы
- **Один игрок**
- **Кооп на одном ПК** — второй игрок на стрелках (автоприцел) или на геймпаде
- **Онлайн до 4 игроков** — хост создаёт комнату, друзья входят по коду (WebRTC через PeerJS, нужен интернет)

## Управление
| Действие | Клавиши |
|---|---|
| Движение | W A S D |
| Прицел / огонь | мышь / ЛКМ |
| Рывок (неуязвимость) | Пробел / ПКМ |
| Оружие | 1–6, колесо, Q / E |
| Нова (ульта) | F |
| Пауза / звук | Esc / M |

## Запуск локально
Открыть `index.html` в Chrome или Edge.
