# NEON STORM

Неоновый аренный 2D-шутер в браузере: бесконечные волны, боссы, 11 видов оружия, 4 карты с интерактивными объектами, 21 улучшение.
Вся графика и звук генерируются кодом — никаких ассетов.

**Играть:** https://backwardzz.github.io/neon-storm/

## Режимы
- **Один игрок**
- **Кооп на одном ПК** — второй игрок на стрелках (автоприцел) или на геймпаде
- **Онлайн до 4 игроков** — хост создаёт комнату, друзья входят по коду (WebRTC через PeerJS, нужен интернет)

## Обновление 2.0
- **Оружие:** Лазер (непрерывный луч), Огнемёт (поджигает), Дископил (возвращается), Кластер (разлетается на бомбочки), Тесла (цепная молния с автонаведением).
- **4 сектора:** Неоновый город, Реактор, Кибер-решётка, Токсичный каньон. После каждого босса — переход в новый сектор.
- **На картах:** телепорты, ускорители, аптечные станции, турели для захвата (встань рядом), электрополя, которые бьют всех внутри.
- **Задания на карте:** взломать терминалы, доставить энергоячейки в реактор, обезвредить бомбу до взрыва.
- **Враги:** Щитоносец (блокирует выстрелы спереди), Фантом (телепортируется), Лекарь (лечит других врагов). У босса — вращающийся лазер.
- **Бонусы с врагов:** Ярость (x2 урон), Форсаж, Щит, Магнит.

## Цели
- **Задания волны** — с 2-й волны у каждой волны случайное задание: удержать зону, поймать элитного врага, пройти без урона, зачистить на время, терминалы, энергоячейки, бомба и др. Награда — бесплатное улучшение, ящик оружия или лечение.
- **Миссии** — 32 достижения между забегами, звания и 7 скинов персонажа, открываемых за звёзды (меню → «Миссии и скины»).

## Игра по одному Wi-Fi (без интернета)
Если комната по коду не подключается (мешает роутер):
1. [Скачай игру](https://github.com/backwardzz/neon-storm/archive/refs/heads/main.zip) на один ноутбук и распакуй.
2. Запусти `Запустить LAN-сервер.bat` и нажми «Разрешить», если Windows спросит про доступ к сети.
3. Открой адрес, который он покажет (`http://192.168.x.x:8777`), в браузере на всех ноутбуках.
4. «Онлайн / Wi-Fi» → блок «По одному Wi-Fi» → один жмёт «Создать», остальные «Войти».

## Управление
| Действие | Клавиши |
|---|---|
| Движение | W A S D |
| Прицел / огонь | мышь / ЛКМ |
| Рывок (неуязвимость) | Пробел / ПКМ |
| Оружие | 1–0 (по порядку подобранного), колесо, Q / E |
| Нова (ульта) | F |
| Пауза / звук / графика | Esc / M / G |

## Запуск локально
Открыть `index.html` в Chrome или Edge.
